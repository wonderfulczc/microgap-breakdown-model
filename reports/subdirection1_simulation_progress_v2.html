平台内部有哪些具体能力

电场

输入：实际几何、电压、材料
输出电势、E场、Emax、高场区；回答击穿可能从哪里开始。

二维 / 三维流注

输入：场、气体、初始电荷
输出 ne/np/nn、空间电荷、流注头、速度与桥接过程。

电流与能量

输入：放电状态、边界条件
输出导电电流、current moment、Joule功率和通道状态。

原生 RF

输入：守恒电流、空间电荷
输出Jefimenko场、时域波形、频谱、可信带和机制归因。

thermal / RLC

输入：Joule交接、回路参数
输出通道电阻、Vport、Iport和端口频谱。

全波传播

输入：Tx/Rx、结构、距离
输出S11、S21、传递函数、接收波形和频谱。

实验验证

输入：VNA、示波器、元数据
分析距离、方向、重复性、不确定度及仿真—实验差异。

统一可追溯

输入：工况配置与原始文件
保留来源、参数、版本和状态，避免历史结果被覆盖。

Appendix B

正式仿真与实验闭环需要准备什么输入

电极与工况

  • geometry
  • gap
  • tip radius / alignment
  • voltage
  • material / coating / interface

决定局部场和边界条件。

放电计算

  • gas composition
  • pressure / temperature
  • initial electrons
  • mesh
  • time step / duration

决定雪崩、流注和电流分辨率。

传播与接收

  • Tx / Rx geometry
  • distance
  • orientation
  • frequency band
  • reference plane

用于区分发射端与接收链影响。

真实实验

  • VNA .s1p / .s2p
  • scope waveform CSV
  • instrument metadata
  • calibration metadata
  • uncertainty metadata

缺少元数据时不能完成正式科学验证。

正式工况的关键不是“只有一条波形”，而是同时保留几何、单位、仪器、校准和不确定度。
