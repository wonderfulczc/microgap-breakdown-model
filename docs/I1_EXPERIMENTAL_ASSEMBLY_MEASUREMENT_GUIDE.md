# I1 实际装置几何与高频连接测绘指南

版本：I1-PHYSICAL-ASSEMBLY-1.0；日期：2026-10-20。
本文件是输入规范，不是本装置参数测量结果。软件入口位于
`adapters/i1_cold_physics_v3_5/`，原V3.4导体几何、外域响应和源装配合同继续适用。

## 1. 分清五类数据

1. 几何：位置、尺寸、法向、材料和坐标变换。
2. 拓扑：哪些端子真正连接，触发前后开关/整流是否隔离TENG，屏蔽与地如何连接。
3. 静电或高频响应：来源绑定的电容、边界算子、S参数；不能由几何标签猜出。
4. 动态分布：表面电荷密度、导体空间电流及时间层；总Q或总I不能唯一给出分布。
5. 标定：测量方法、带宽、误差和适用条件；schema通过不表示物理标定通过。

身份选 `PARAMETRIC_B0_LOCAL`、`SOURCE_BOUND_MEASURED_ASSEMBLY` 或
`SYNTHETIC_ENGINEERING_ASSEMBLY`。每个section携带value、source(file/SHA256)、
uncertainty、reason。未知用value=null及具体reason，不用零或人工参考替代。
有来源的数值必须与对应JSON文件内容一致，避免只引用一个无关文件的哈希。

| 项目 | 可用测量工具/资料 | 提交单位与内容 | 当前状态 |

| 引线及回流 | 整体多视角照片、卡尺、CAD或标定三维点 | xyz均为m、有限截面积m2 | 未知 |

Rs=3 ohm、L=100 nH、Cext=101 pF是参考设计值，不自动成为测量值。
Cext位于串联支路；源内CT、气隙Cp、对地/引线电容必须分开。
历史1 mm人工LTE柱不是实际70 um热通道。70 um名义间隙也不证明等效导电长度。

## 3. 照片与坐标

提供整体俯视、侧视、与轴向相关的第三视角；局部图覆盖两个针尖及接触面。
每张图带标尺、拍摄方向、镜头/倍率、时间和原图文件SHA。无法恢复深度的二维图不补造z坐标。
建议定义间隙中点为原点、双针公共轴为z、右手系x/y。可以使用其他坐标系，但须提交
4x4刚体变换、单位、原点和正向。H/Return永久身份不随电压极性改变。

CAD保留原件和导出件，标明单位及版本。折线JSON至少给出：

```json
{
  "coordinate_system": "CARTESIAN_XYZ_SI",
  "xyz_m": null,
  "lead_segments": null,
  "return_segments": null,
  "reason": "待提供实际节点、有限截面和接触面"
}
```

每段需要起终节点、截面积或半径来源、材料、所属支路、参考面；每个电极接触点
需要匹配局部/全局面ID和方向。V3.4已有有限面片和导体图合同可复用。
任意曲线CAD到传播FV网格的保守映射不是标签自动提供的功能。

## 4. H/Return与电压电流测量

明确差分电压的两个实体接触面。Return=0仅为电势规范，不自动添加接地线。
逐项标明电流探头环绕哪条支路；总回路电流不自动等于气体传导电流。
提交触发源、采样间隔、时间单位、探头极性、转换倍率、输入阻抗/电容及延迟。
不同实验记录不能移动峰值后当成同步V/I；未校准幅值不能用于逐点物理电阻。
RF接收波形另需天线位置、方向、线缆、终端及接收传递函数。

## 5. 电容、S参数和源状态

电容或阻抗测量须给出仪器、频率、校准/去嵌入参考面、连接图、端口数及不确定度。
S参数可用Touchstone原文件，并说明参考阻抗、端口映射、频率范围和校准条件。
不能把包含夹具寄生的响应不加说明地用于局部截断域Cp。

TENG需在说明机械位置x0和连接状态后提供CT(x0)、Voc(x0)、qT0或可换算初态。
500--800 V击穿前名义电压不决定101 pF预充电荷，也不等于击穿后恒压源。
若高频回路隔离了TENG，必须使用相应实际拓扑，不强行纳入CT串联效应。
本轮未实施真实TENG热串联运行；已有热入口只接受明示10 V合成参考。

## 6. 来源等级和误差

每个量区分直接测量、CAD、数值响应、文献近似和合成制造输入。
保存原文件SHA、单位、样本/器件ID、日期、测量方法、重复性、系统误差及覆盖域。
缺误差时写null+NOT_MEASURED，不写0。合成输入的“精确定义”不是实验零误差。
取得实际几何不代表离子迁移率、表面gamma、LTE或源参数同时被标定。

## 7. 数据不足时仍可做什么

现有工具可以运行来源明确的B0局部冷FULL，或独立给定T/p、显式初始零速度的
G1热柱串联参考；输出各自局部端口/电流、状态、预算和来源。
热柱局部Jz依据轴向均匀假设输出，不填造自由电荷密度以生成完整RF源。
可校验完整合成装置的连接和参考面，不复制其布局为实验导线。

没有全局几何、外域响应和表面分布时，完整真实全局源明确拒绝。
没有材料能量、质量/动量、空间投影、LTE证据和统一能量参考时，自动冷热切换返回
MISSING_PHYSICAL_CLOSURE。下一项优先工作是取得并绑定同一参考面的实际外部装置输入包，
不是再延长人工热轨迹。
