## 实际源码与参数

- `ColdPhysics.hpp/.cpp`：显式版本/能力、正离子上风漂移+中心扩散、轴对称有限体积、壁面收集与正性dt；负离子仍仅反应。
- `StreamerSolver.hpp/.cpp`：将离子通量、阴极发射的电子边界散度、气体SP3及真实机制账本接入原生step；MorrowLowke、ReactionModel、电子ISG0及Poisson空间公式未改。
- `sp3_geometry.hpp/.cpp`：3个耦合双分量块，内部金属无未知量/无穿越链接，原六分量SP3的吸收Robin边界；没有仅删除guard。
- `ColdFullProvider.hpp/.cpp`及原FP3 snapshot/network/stable辅助头：复用完整内存事务、全部已启用物种面流及同算子电荷/场功。
- `adapters/i1_cold_physics_v3/`：统一输入校验、native runner、PortDescriptor/电容互斥守卫、隔离测试及离线归档；没有第二套PDE/RLC。

条件参数mu_p=2e-4 m2/(V s)、D_p=5e-6 m2/s、gamma_i=0.02均为显式数学测试参数。离子EN许可0–1e5 Td、T290–310 K、p1e5–1.1e5 Pa也是测试域声明，不是空气高场标定。SP3原开发激发比例0.1保持来源身份。gamma没有采用此前理想gamma_critical。场初态与旧2.5um B0 mask逐字节相同；初始中性电子/正离子各96.2172148202，初始floor电荷改变为0源于ne=np配对，而不是忽略修正。

## 结论与唯一后续依赖

离子输运、真实离子壁面驱动发射、内部金属SP3和局部物种电荷端口已形成可运行的条件性工程连接；B0短窗证据止于1 ps共同账本。它不建立自持击穿、20 ohm通道或实验RF。旧C1/V5/V6/V7、FP3/FP4/TENG和形成律Gate保持。

下一项架构依赖是**来源和有效域明确的离子输运/材料表面参数包及其端口能力约束**；同时把已报告电功精度与发射能量缺项作为独立限制交科学审查。真实全局参考面、材料能量和RF源/接收映射未由此完成。本任务停止，不追加轨迹或扫描。
