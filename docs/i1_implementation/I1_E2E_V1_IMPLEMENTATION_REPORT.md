# I1-E2E-V1：条件性放电—电路—场—接收工具

日期：2026-10-20。实际分支architecture-v2.1-ultrafast-rf，
历史HEAD为8ec25920adff63a0b1a875c620b9a32105458ad7；运行身份包含未提交GENERIC_DEV。

## 1. 最重要的结论

**P0链路已贯通。** 一个配置入口实际调用P1 TENG几何/电荷源、原FP3/TENG串联电路、
守恒GlobalSourcePacket、Stage F Jefimenko、Stage H方向投影和新接收电压模型。
合成100ns得到非零vg、i、E和Vrx，6个完整同极性周期。

**P1物理ROM已实现并运行。** 不是预设R(t)：电子/正离子保守漂移扩散、
原生依据的电离/附着/复合、静止负离子、吸收/可配置二次发射、
一维自洽Poisson及同网络电极储荷真实参与trial/commit。
外部R改变后，端口电压及内部ne/np/nn发生可计算变化；此次变化很弱，
不能把确定性差异升级为有独立误差界的器件物理敏感性。

**P2只完成授权的R和间隙对照。** L/C接受任意合法正值配置，但未另运行其敏感性矩阵。
针尖曲率/锥角在一维平面映射中仅保留几何身份，不虚构场增强；
本轮几何比较改变真实进入模型的gap。未运行项显式NOT_RUN。

**P3仍有精度限制。** 合成冒烟20ps步长没有解析1ps端口RC快模态：
独立矩阵指数给出早期vg最大尺度误差0.818255。
因此只接受完整链路与较晚窗口检查，**不接受启动段电压精度**。
没有为此追加第五条轨迹或覆盖原输出。最新入口会明确警告快模态欠解析。
真实TENG、实际通道形成、全局源、天线及实验RF仍未验证。

## 2. 软件与实际复用

新增代码均在`adapters/i1_e2e/`：

- pipeline.py：I1PredictivePipeline、GeometryProvider、模式分派、参数/初态及时间精度检查。
- rom.py：AxialParticlePort与ROMSeriesCircuit；前者实现新一维物种/场模型，
  后者只调整原TENG电路的场能库存，不复制原残差/RLC积分器。
- radiation.py：有限体积等效导体源、旧F/H消费者连接、ReceiverVoltageModel。
- interfaces.py：共享ChannelStateEnvelope，旧冷/热结果和新ROM均保留真实时间层/缺失量。
- fixtures/run_rom/test_e2e/review：限定案例、局部制造检查、离线对照及独立解析参考。

原电子系数与反应接口来自`adapters/i1_conductive_channel/kinetics.py`，
原生C++源和既有parity记录本轮只读。源CT/Voc由P1制造公式生成，
QT由原TENGSeriesCircuit真正演化。没有新常数拟合、电子增长系数、R_floor或热化效率。

支持的首版拓扑只有TENG串联L-Rs-Cext-gap。没有冒称任意网表。
旧COLD_FULL/GIVEN_THERMAL_SERIES通过现有V3.5入口委派，保留原先可运行性与限制；
本轮仅从归档结果测试统一状态合同，没有新Stage C或G1步。
AUTO直接拒绝，不构造热态。ROM接口与FULL/G1并未自动获得状态/能量映射。

## 3. 固定输入与四个实际案例

四例使用相同P1合成TENG：
xT=0.1mm、sigma=1e-6C/m2、PET/FEP各50um、epsr=3/2、面积1.6e-3m2，
胶层不在理想串联路径的合成假设，CT=100.000239pF、Voc=11.294091V。
这是明确参考源，不是500–800V实验充电历史。
i0=Vc0=QT0=0，Vp0=Voc，仅作开路平衡后接入端口的数学事件。

| 案例 | 通道 | Rs | gap | 实际终点/接受宏步 |
|---|---|---:|---:|---|
| synthetic_e2e | 5ohm并联0.2pF数学端口 | 3ohm | 70um标签 | 100ns / 5000 |
| rom_R3 | 自主物种/一维Poisson | 3ohm | 70um | 200ps / 100 |
| rom_R300 | 同一个ROM、只改Rs | 300ohm | 70um | 200ps / 100 |
| rom_gap100um | 同源/电路、只改gap | 3ohm | 100um | 200ps / 100 |

共同L=100nH、Cext=101pF；它们只是fixture值，程序并不锁死。
ROM为12单元、有效半径50um，ne=np=1e16m^-3、nn=0的均匀中性种子，
1atm/300K。约5498初始电子与历史约96个Gaussian电子不是同一状态。
100um例保留相同密度和截面，初始粒子库存随体积变大，未伪造等粒子数比较。
离子mu/D是显式C类参数；gamma=0，独立壁面测试另验证非零gamma与极性。
没有新形成后高密度轨迹、热模型或扫描。

## 4. 完整链路冒烟结果与独立限制

合成电路峰值|i|=0.221573425A，数学支路累计耗散2.015022793nJ。
等效源是长4mm、非零1mm体素支撑的导体短段，电容性端点回流明确，
不是将i_port填到70um气体体积。源图逐区间电荷连续性残差为0。
SourceSeries同时保存rho与J；另一闭合回路类型通过局部连续性测试，没有额外传播案例。

接收位置[10,0,0]m；有效高度[0,0,0.05]m；天线/负载各50ohm。
真实Stage H投影后，Vrx=0.5*h_eff*E；这是未标定的条件接收器。
源最近位置的传播延迟33.356410ns。E峰值4.432706mV/m、负载Vrx峰值110.817649uV。
这些峰值保留数值/初始边缘误差限制，不是实验预测。

时域正/负峰各7个、完整同极性周期6个，中位正峰间隔14.148ns；
对数衰减拟合时间约23.80ns，仅描述这条合成波形。
Hann去均值频谱，独立bin间隔约9.518MHz，10–80MHz内最大bin约66.627MHz；
不能把bin中心称为精确频率，更不是50MHz校准。没有FFT补零。

独立常系数矩阵指数与电小偶极解析式在retarded 5--90ns窗口核对，
Stage F电场相对L2差5.09874e-4，低于事前离线检查目标2%。
这不掩盖早期RC欠解析。dt/(R Cp)=20，前100接受节点的vg尺度误差最高0.818255；
晚期场与能量闭合不能认证该启动段。

旧中心时间导数跨启动点插值产生提前泄漏，最大原始幅值2.668238mV/m。
原始值保留于transmitter_field.csv；已知零前史下使用明确的因果支撑门，
最早传播到达前输出零。该门不是已验证的高阶启动边缘处理。
未来对启动高频尖峰的定量使用，必须先改善时间分辨率和因果时间导数。

两个R例源、初态、ROM、几何、接收器完全相同；比较脚本逐字段检查。
Rs变化不是仅改变外围衰减：ne差约-6.3389e9m^-3，相对约-7.63e-7，
np差约+8.0607e6m^-3；实际端口电压进入后续粒子pre层，产生内部状态差。
差异高于浮点舍入，但没有独立时间/网格收敛界，**不认证其微弱物理灵敏度**。
粒子推进是显式滞后，不伪称已经实现全隐式PDE-circuit求解。

此源电压下碰撞电离事件积分约6.11e-34，附着事件约31.29；
电子减少主要表现为吸收/输运与少量附着，不是雪崩形成成熟火花。
Rdiag约50Mohm只是冻结漂移诊断，端口仍由面通量与QH计算，
没有把它作为RLC电阻或预测20–200ohm贯通。

几何间隙真实改变dz、体积、Poisson链接、Cp、E、输运和反应，不只是改标签。
针尖曲率效果在本一维平面近似中未建模，未运行的L/C/曲率对照均明确列出。

ROM接收窗口只有约206ps，FFT bin约4.822GHz，10–80MHz没有可用bin。
原始通用周期计数仍保留，reviewed指标明确INSUFFICIENT_WINDOW_FOR_10_80_MHZ，
不把该短窗快速瞬态称为目标RF谱峰。
接收有效高度及有限源支撑在这些快速瞬态下也没有实验频带资格。

## 7. 能力与下一项理论重点

已经可做：单配置从TENG/RLC到动态ROM、有限等效发射场、明确接收器的条件性比较。
实际场景仍受源初态、等效截面、离子/表面参数、近电极、空间降阶及接收模型限制；
限制被显式输出，但没有阻止P0/P1软件实施。

FULL和G1保持独立可用，通过共同电压/电流/电荷/能量结果合同导出。
没有新冷、热或自动切换轨迹；AUTO仍MISSING_PHYSICAL_CLOSURE。
条件辐射为单向后处理，辐射反作用/源负载反馈未计入电路；不报告RF能量转换效率。

最值得发展的理论关系是**FULL到ROM的保守状态/端口投影**：
同参考面下同时约束截面积分物种、面通量、QH与Wcond，并把G1材料能映射作为独立闭合。
不能只拟合R(t)；启动快模态与边界时间导数的精度修正应先于使用尖峰作物理解释。
本轮停止，不自动进行这项后续验证或新参数扫描。
