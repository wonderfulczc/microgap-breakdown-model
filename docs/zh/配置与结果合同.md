# 配置与结果合同

统一配置采用 `common + backend-specific` 结构。公共字段为 `case_id`、`workflow.type`、
`backend`、`output.directory`、`schema_version`、`contract_version` 和 `model_version`。
频率统一以带单位键表达；示例输入使用 MHz，解析后的物理模块仍使用 Hz。

每个新 case 目录包含 `config_input.yaml`、`config_resolved.yaml`、`run_manifest.json`、
`provenance.json`、`status.json` 及 `logs/data/figures/report`。清单记录 Git 提交、命令、
配置和输入/输出哈希、后端、版本、运行时间、退出状态及科学状态。旧结果不会被迁移或覆盖。
