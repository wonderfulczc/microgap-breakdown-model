# 开源许可与知识产权边界

本文是工程决策说明，不是法律意见。项目源代码许可证、论文版权、专利或发明权、实验与
仿真数据权利、第三方后端许可证是不同对象，必须分别确认。

正式 `LICENSE` 中的 Apache-2.0 适用于本项目软件代码。它不自动改变论文版权、专利权、
实验数据权利、第三方后端许可证或学校可能拥有的知识产权。当前版权持有人状态采用
`COPYRIGHT_HOLDER_STATUS=USER_AUTHOR_DECLARATION_ONLY`；若机构政策要求进一步确认，应由
用户按学校知识产权流程处理。本说明不构成法律意见。

软件开源不会自动放弃论文署名或作者权，也不等同于许可论文全文。公开代码可能构成专利
意义上的公开披露；是否影响未来专利申请取决于法域、公开时间与申请策略。计划申请专利、
许可企业使用或进行技术转让时，应在公开前咨询学校或机构的技术转移与法律部门。

源代码许可证不会自动覆盖真实实验数据、外部归档的大型仿真数据或论文插图。数据应使用
独立的数据政策和许可证。Afivo、openEMS、CSXCAD、fparser、AppCSXCAD 和 COMSOL
不随项目包分发；若未来改为捆绑、链接或重新分发，必须按实际组合重新审查其 GPL、LGPL
或专有许可义务。
