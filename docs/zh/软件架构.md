# 软件架构

核心层包含 C++17/PETSc/MPI 求解器、`streamer_rf` Python 包、合同和测试。外部层包含
Afivo-streamer、openEMS/CSXCAD 以及仅通过接口交接的 COMSOL。数据层区分小型冻结参考、
可重建大型科学数据和仅供开发的 Stage-I 合成夹具。

A-J 数据链依次覆盖数值基础、静电几何、二维/三维 streamer、本征 Jefimenko 场、热通道
与 RLC、瞬态端口、全波结构/接收机及实验验证。RP-1 只在这些冻结接口上增加 CLI、配置、
来源追踪和长期维护机制。详细英文阶段文档仍是证据附件；本文件与 README.zh-CN.md
规定科研开发入口和边界。
