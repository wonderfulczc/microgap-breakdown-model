# Release Preparation RP-3B

RP-1 至 RP-3B 是非正式 Stage 的发布准备工作，提供可安装 Python 包、统一 CLI、配置、
长期科研维护框架以及用户确认的 Apache-2.0/Citation 元数据。它们不改变 A-J 物理和科学
状态，也不创建 release、tag 或上传 PyPI。

当前 `RC1_ALLOWED=true`，`PUBLIC_RELEASE_READY=READY_FOR_RELEASE_CANDIDATE`；当前版本仍为
`0.1.0.dev0`，尚未公开发布。科学状态仍为
`STAGE_I_SCIENTIFIC_VALIDATION=PENDING_REAL_EXPERIMENT`。
