# 软件引用与学术署名说明

`CITATION.cff` 用于告诉使用者如何引用软件版本，不等同于论文作者资格，也不能替代论文、
数据集和第三方后端各自的引用要求。

- **项目软件**：引用正式发布的软件名、作者、版本、仓库或归档标识和发布日期。
- **项目论文**：仅在用户确定引用策略和具体论文后加入，不虚构 DOI。
- **第三方后端**：Afivo、PETSc、Open MPI、openEMS/CSXCAD 等按各自要求单独引用。
- **数据集**：真实实验数据和大型仿真数据使用自己的作者、版本、许可证和归档标识。

`authors` 应列实际承担本项目软件创作责任的软件作者，并按用户确认顺序填写。科学贡献者、
导师或顾问可在项目文档、贡献说明或 CFF 的适当角色中记录，但不应自动转化为软件作者。
第三方后端作者不是本项目作者，应通过第三方 notices 和后端 citation 处理。

CFF schema 的最低字段为 `cff-version`、`message`、`title`、`authors`。本项目正式发行
还要求确认 `repository-code`、`license`、`version`、`date-released` 和引用策略。
ORCID、机构、email、DOI 与 preferred paper 均不得在未确认时填写。
