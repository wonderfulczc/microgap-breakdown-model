# Citation 元数据填写说明

正式 `CITATION.cff` 尚未创建。候选文件 `CITATION.cff.candidate` 中的占位符必须由用户确认。

必须提供：作者姓名及顺序、preferred citation name、正式 repository URL、项目许可证、
是否采用 `0.1.0rc1` 候选版本。发布时还必须确认 release date。

可选字段：ORCID、机构、软件 DOI、preferred citation paper。未提供时可省略，禁止推测。
项目名 `microgap-rf` 是 Python distribution；`streamer_rf` 是 import package；
`microgap-rf` 同时是 CLI 名称。
