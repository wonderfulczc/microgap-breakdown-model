# 文献维护流程

论文先进入 `literature_registry.yaml`，影响状态由专家填写，不能由标题自动推断。对项目有
实际影响的论文再填写 evidence card。`microgap-rf literature impact PAPER_ID` 只读取登记信息，
输出 `NO_CHANGE`、`REVIEW` 或 `CHANGE_REQUEST_REQUIRED`，不会修改代码。

固定链为：登记 -> 专家审阅 -> 影响分析 -> 决策记录 -> 可选 change request -> 最小实现
-> 定向回归 -> 全局非回归。论文全文仅在许可证明确允许时保存。
