# DEC-0001 v2.1超快RF源动力学机制层

- 决策问题：如何在不改动冻结v2.0物理求解器的前提下，将streamer事件拓扑与局部超快电子动力学接入现有Stage-F current-moment/RF解释链。
- 触发来源：Koile, Liu & Dwyer (2021), *Radio Frequency Emissions From Streamer Collisions in Subbreakdown Fields*。
- 相关文献：`KOILE_2021_STREAMER_COLLISION_RF`，DOI `10.1029/2021GL096214`。
- 现有实现：Stage F已有 `M(t)=integral(J_RF)dV`、`dM/dt`、频谱可信门，以及HCE/ACC/REDIS机制项；缺少事件ROI、局部 `tau_i` / `tau_M` 和事件时间分辨率合同。
- 候选修改：在Stage C/E与Stage F之间增加内部逻辑层 `ULTRAFAST_SOURCE_KINETICS`，只定义合同与未来接口，不创建新正式Stage。
- 影响范围：未来B-RF1、C-R5、E-R2、F-R5A/F-R5B/F-R6、I-R1。
- 最终判断：`APPROVED_FOR_R0_CONTRACT_ONLY`
- 日期/版本：2026-09-22；`simulation_architecture_version = v2.1`；软件版本保持 `0.1.0`。

## 不能直接照搬的内容

Koile研究针对厘米尺度、锥形hydrometeor、近似均匀背景场和对向streamer collision。本项目针对微米级微间隙、实际金属电极、强非均匀局部场，并可能出现传播、头部相互作用、碰撞、电极附着、桥接和多头相互作用。

因此：

1. 不得将 `Eamb/Ek` 直接等价为本项目击穿判据。
2. `Ek` 只作为归一化参考尺度，不是微间隙击穿的充分判据。
3. 本项目定义 `eta_0 = E0(event region)/Ek` 与 `eta_peak = Epeak(event region,t)/Ek`，并要求记录事件ROI和场统计方法。
4. Koile碰撞结果不能自动推广到 `PROPAGATION`、`ELECTRODE_ATTACHMENT` 或 `BRIDGING`。
5. 文献中的厘米尺度Table 1只作为F-R5A处理与趋势基准，不作为本项目预测值。

## 两级机制解释

- Level 1：HCE / ACC / REDIS回答current moment变化来自流注头电荷演化、加速度还是电流重分布。
- Level 2：`tau_i` / `tau_M` / `eta_peak` / `ne`回答局部电子动力学为何产生该时间尺度。
- 两级互补；v2.1不删除、不改写Level 1。

## Pi_RF定位

`Pi_RF = tau_M/tau_i` 是本项目v2.1的 `DIAGNOSTIC_CANDIDATE`，不是Koile原文参数。当前不得称为新物理定律、新无量纲数或首次提出；进入科学结论前必须完成数值扫描和文献创新性审查。

## 处理与时间分辨率边界

- Koile-compatible处理链保留uniform resampling、10点移动平均、`dM/dt`、Tukey窗、12 ns zero padding、FFT和ESD。
- 论文未报告Tukey `alpha`；项目基准可使用候选默认值，但必须标明不是论文原值并进行敏感性比较。
- zero padding只细化频率采样网格，不增加由原始记录时长决定的真实物理频率分辨率。
- 目标脉宽至少需要5个有效时间样本，10个为优选；不足时必须标记 `NOT_RESOLVED_TEMPORAL_RESOLUTION`，插值不得升级状态。
- RAW、KOILE_COMPATIBLE、NO_SMOOTHING、ALTERNATIVE_WINDOW均须保留；处理方法改变结论时标记 `PROCESSING_SENSITIVE`。

## 保持不变的边界

- 正式Stage仍仅为A-J，不创建Stage K。
- Stage G thermal/RLC与Stage H full-wave不修改。
- `S_native(f) != S_port(f) != S_receiver(f)`。
- `NATIVE_RF_350MHZ = NOT_RESOLVED`。
- `STAGE_I_SCIENTIFIC_VALIDATION = PENDING_REAL_EXPERIMENT`。
