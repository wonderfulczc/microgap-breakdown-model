# microgap-rf 0.1.0 发行说明

## 版本定位

`microgap-rf 0.1.0` 是冻结 A-J 科研软件架构后的首个正式软件版本。它提供可安装、
配置驱动、可追溯和资源友好的多物理仿真与实验验证工具链。

## 主要功能

- PETSc/MPI 二维 streamer 框架；
- Afivo 三维外部后端接口；
- Stage-F Jefimenko 本征 RF 和信任频带合同；
- 热通道、RLC 与瞬态端口链路；
- openEMS/CSXCAD 外部全波后端和接收机传递链；
- Stage-I VNA/示波器数据合同、距离/方位/重复性/不确定度管线；
- 统一 CLI、配置、provenance、文献维护和科学变更治理。

## 快速安装与 CLI

```bash
python3 -m venv .venv
.venv/bin/pip install microgap_rf-0.1.0-py3-none-any.whl
microgap-rf --version
microgap-rf doctor
microgap-rf run examples/configs/smoke.yaml
microgap-rf report rp1_smoke
```

## 外部后端

Afivo-streamer、openEMS、CSXCAD、fparser 和 AppCSXCAD 不包含在本发行制品中。COMSOL 仍是外部专有工具工作流。

## 软件与科学状态

软件工具链、测试、打包和合成 dry-run 已通过。但科学状态仍为：

- `STAGE_I_SCIENTIFIC_VALIDATION=PENDING_REAL_EXPERIMENT`；
- `PUBLIC_SCIENTIFIC_VALIDATION_COMPLETE=false`；
- `SYSTEM_350MHZ_VALIDATION=NOT_MEASURED`；
- `NATIVE_RF_350MHZ=NOT_RESOLVED`。

## 已知技术债务

- H2：`VNA_MEASUREMENT_PENDING`；
- H3：`FULL_WAVE_LOADING_MISMATCH_HIGH` 且 `FULL_WAVE_LOADING_FEEDBACK_NOT_COUPLED`；
- H4：`RECEIVER_TRANSFER_MESH_SENSITIVITY_PRESENT`，绝对幅值为 `NUMERICAL_REFERENCE_ONLY`；
- Stage5：`FULL_MAXWELL_REFERENCE_PENDING`；
- Stage-F：可信 FFT bins 稀疏；
- 实际 Tx/Rx 生产几何和真实实验数据待提供。

## 数据政策

标准制品仅包含源码、小型合同和必要参考数据。多 GB Afivo/Stage-F 原始数据、外部后端和
Stage-I 24 MB synthetic fixture 不作为本次 GitHub Release asset。Synthetic data 不是实验数据。
