# microgap-rf 0.1.0rc1 候选发行说明

## 版本定位

`0.1.0rc1` 是冻结 A-J 科研工具架构后的首个候选构建，用于正式发行前的软件验收。
它不是正式 `0.1.0`，也不提升任何科学验证状态。

## 主要能力

软件包含 PETSc/MPI 二维 streamer 框架、Afivo 外部三维接口、Jefimenko 本征 RF、
热通道/RLC/端口链、openEMS 外部全波接口、Stage-I 验证基础设施、统一 CLI、配置驱动、
文献维护与科学变更治理。

## 安装与CLI示例

```bash
pip install microgap_rf-0.1.0rc1-py3-none-any.whl
microgap-rf --version
microgap-rf doctor
microgap-rf run smoke.yaml
microgap-rf report installed_wheel_smoke
```

## 外部后端

Afivo、openEMS、CSXCAD、fparser、AppCSXCAD 和 COMSOL 不随标准 wheel/sdist 分发。
用户通过文档化环境变量和文件接口连接这些后端。

## 已验证的软件能力

构建、轻量测试、配置/合同解析、频谱与验证 API、发行审计和 smoke 工作流经过自动验收。
这表示工具链可运行，不表示真实实验已经验证物理预测。

## 科学状态与已知限制

- `STAGE_I_SCIENTIFIC_VALIDATION=PENDING_REAL_EXPERIMENT`；
- H2：`VNA_MEASUREMENT_PENDING`；
- H3：`FULL_WAVE_LOADING_MISMATCH_HIGH`，且反馈未耦合；
- H4：接收机传递存在 mesh sensitivity，绝对幅值为 `NUMERICAL_REFERENCE_ONLY`；
- Stage5：`FULL_MAXWELL_REFERENCE_PENDING`；
- Stage-F：可信 FFT bins 稀疏；
- 生产 Tx/Rx geometry 和真实实验数据仍待提供；
- 350 MHz 本征 RF 为 `NOT_RESOLVED`，不等于零。

## 数据政策

多 GB Afivo/Stage-F 原始数据不进入标准发行包；Stage-I 约 24 MB 合成夹具保持
`KEEP_IN_REPOSITORY_ONLY`，不属于实验数据。
