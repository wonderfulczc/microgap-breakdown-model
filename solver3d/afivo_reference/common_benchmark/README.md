This directory defines the Stage D2 common benchmark contract. It does not vendor
Afivo-streamer source; the external pinned backend remains at:

## Scope

Stage D2 establishes a shared mathematical problem for later PETSc2D/Afivo3D
cross-validation. It is not a dynamic streamer cross-validation stage.

Benchmarks:

- `D2-B0-common-physics`: frozen PETSc Morrow-Lowke transport export and
  pointwise three-species chemistry mapping, photoionization off.
- `D2-B1-axisymmetric-electrostatic`: static zero-plasma rod/plane electrostatic
  problem. Afivo uses the true 3D Cartesian `standard_3d` backend with a
  centered capped rod; PETSc uses a D2-only axisymmetric finite-volume/PETSc
  sampler with the same homogeneous outer boundary convention.

All quantities use SI units.

## Files

- `common_case.yaml`: shared parameter contract.
- `geometry_contract.json`: machine-readable B1 geometry/boundary contract.
- `transport/generated/`: generated by `build/bin/generate_common_transport`.
- `afivo/d2_b1_*.cfg`: Afivo true-3D static lineout configurations.
- `petsc/generated/`: generated PETSc B1 axis CSV files.
- `compare/compare_stage_d2.py`: transport/chemistry/electrostatic metrics.

## Commands

Generate B0 transport and chemistry data:

```sh
build/bin/generate_common_transport solver3d/afivo_reference/common_benchmark/transport/generated
```

Run PETSc B1:

```sh
build/bin/stage_d2_petsc_b1 --resolution coarse --out solver3d/afivo_reference/common_benchmark/petsc/generated/d2_b1_petsc_coarse.csv
build/bin/stage_d2_petsc_b1 --resolution medium --out solver3d/afivo_reference/common_benchmark/petsc/generated/d2_b1_petsc_medium.csv
```

Run Afivo B1 from the external backend:

```sh
OMP_NUM_THREADS=2 /home/helianthusczc/projects/afivo-streamer/programs/standard_3d/streamer \
  solver3d/afivo_reference/common_benchmark/afivo/d2_b1_coarse.cfg
OMP_NUM_THREADS=2 /home/helianthusczc/projects/afivo-streamer/programs/standard_3d/streamer \
  solver3d/afivo_reference/common_benchmark/afivo/d2_b1_medium.cfg
```

Compare:

```sh
.venv/bin/python solver3d/afivo_reference/common_benchmark/compare/compare_stage_d2.py b0 \
  --transport solver3d/afivo_reference/common_benchmark/transport/generated/transport_roundtrip.csv \
  --chemistry solver3d/afivo_reference/common_benchmark/transport/generated/chemistry_pointwise.csv

.venv/bin/python solver3d/afivo_reference/common_benchmark/compare/compare_stage_d2.py electrostatic \
  --petsc solver3d/afivo_reference/common_benchmark/petsc/generated/d2_b1_petsc_medium.csv \
  --afivo solver3d/afivo_reference/common_benchmark/afivo/output/d2_b1_medium_line_000000.txt
```

## Known Limits

Afivo old-style transport has one attachment coefficient. The generated old-style
file stores `eta2 + eta3` at the common pressure and temperature. Exact
three-species PETSc chemistry requires the generated reaction-table candidate
`morrow_lowke_common_chemistry.txt`, which tabulates first-order ionization and
attachment frequencies and uses analytic recombination terms.

PETSc and Afivo B1 use different electrode discretizations:

- PETSc: axisymmetric structured cell-center conductor mask with D2
  homogeneous outer boundaries matching Afivo.
- Afivo: Cartesian AMR level-set capped rod, lower Dirichlet ground plane,
  side Neumann zero, top Dirichlet applied voltage.

The B1 acceptance priority is therefore axis `phi(z)` and `|E|(z)` profile, not
tip-cell `Emax` alone.
